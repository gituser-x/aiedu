# 功能与体验路径

| 功能 | 体验方式 | 说明 |
| --- | --- | --- |
| 普通用户注册 | 注册页留空邀请码 | 注册后自动登录，填入邀请码时仍校验 |
| 题库检索 | 找题组卷，关闭 AI 补题 | 可使用共享题库，结果数量受已有资料限制 |
| AI 补题 | 开启 AI，输入“语文2道选择题” | 展示真实外部模型结果及阶段进度 |
| 阅读与完形 | 指定学科、题型与题量 | 公共材料随题保存并关联材料组 |
| 选题组卷 | 加入试卷、用选中题目组卷 | 预览题目并保存，随后再次打开 |
| 异步任务反馈 | 生成时观察页面 | 排队、运行、校验、完成或失败 |
| 试卷上传与识别 | 站内上传入口 | 已有工作流；不包含在最新文本模型验收矩阵中 |

截图来自真实浏览器验收。没有公开原始题库和试卷附件；使用者不应上传敏感或无权处理的资料。
